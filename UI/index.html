Neural Network Setup

Requirements

  • Have Python installed on your device.

Installation & Execution

If you have Python installed, run the following commands:

  • Clone the repository: git clone https://github.com/thefili2/MNIST-Neural-Network-with-Numpy.git
  • Navigate to the folder
  • Install dependencies: pip install tensorflow numpy
  • Run the script: python main.py
